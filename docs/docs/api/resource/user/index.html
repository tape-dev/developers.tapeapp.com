User

Retrieve the current user​

GEThttps://api.tapeapp.com/v1/user

Retrieve the user the credential belongs to, the name of their organization, and what the credential may do. This endpoint requires no capability, and can only ever return the credential's own user.

➡️ Request
curl https://api.tapeapp.com/v1/user \
  -u user_key_replace_with_your_api_key:
⬅️ Response
{
  "user_id": 10000,
  "org_id": 1337,
  "org_name": "Acme Inc.",
  "name": "John Doe",
  "status": "active",
  "role": "owner",
  "email": "john@doe.com",
  "phone": "555 123 456",
  "job_description": "Founder & CEO",
  "authentication": {
    "method": "personal_access_token",
    "scopes": ["apps:read", "records:read"],
    "content_access": {
      "scope": "selected",
      "workspace_ids": [42],
      "app_ids": []
    }
  }
}

The authentication block describes the credential used for the request:

methodscopescontent_access
personal_access_tokenThe token's capabilitiesscope is all, or selected with the selected workspace_ids and app_ids
oauth_access_tokenThe scopes the access token holdsAlways {"scope": "all", "workspace_ids": [], "app_ids": []}
user_keynull — a user API key is unrestrictednull

Retrieve organization users​

GEThttps://api.tapeapp.com/v1/org/user

Retrieve your current organization's users (e.g. the organization with ID 1337):

➡️    Request
curl https://api.tapeapp.com/v1/org/user \
  -u user_key_replace_with_your_api_key:
⬅️    Response
{
  "users": [
    {
      "user_id": 10000,
      "name": "John Doe",
      "org_id": 1337,
      "status": "active",
      "email": "john@doe.com",
      "phone": "555 123 456",
      "role": "owner",
      "job_description": "Founder & CEO"
    },
    {
      "user_id": 10001,
      "name": "Zoe Maxwell",
      "org_id": 1337,
      "status": "active",
      "email": "zoemaxwell10001@me.com",
      "phone": "555 123 457",
      "role": "member",
      "job_description": "Executive"
    }
  ],
  "total": 2
}

Add user to organization​

POSThttps://api.tapeapp.com/v1/org/user

Add a new user to your current organization (e.g. the organization with ID 1337). Include the skip_invitation flag in your request body to skip sending the invitation email upon user creation.

➡️    Request
curl -X POST https://api.tapeapp.com/v1/org/user \
  -u user_key_replace_with_your_api_key: \
  -H "Content-Type: application/json" \
  --data '{
    "name": "Roger Sterling",
    "email": "rsterling-sc@me.com",
    "role": "admin",
    "skip_invitation": true
  }'
⬅️    Response
{
    "user_id": 10002,
    "name": "Roger Sterling",
    "org_id": 1337,
    "status": "active",
    "email": "rsterling-sc@me.com",
    "phone": "555 123 458",
    "role": "admin",
    "job_description": "VP"
}
User Organization Role

The role property to create users needs to be one of "admin", "member" and "guest". This corresponds to the user organization roles documented in the help center. Note that adding admin and member users is a billable event. 💲

Resend user invitation email​

POSThttps://api.tapeapp.com/v1/org/user/{userId}/resend-invitation

Resend an invitation email for an organization user. This will be important when skipping invitations during user creation, and allows sending the invitation email at a dedicated point in time later or repetitively.

➡️    Request
curl -X POST https://api.tapeapp.com/v1/org/user/10000/resend-invitation \
  -u user_key_replace_with_your_api_key:
⬅️    Response
{
}

Update or delete users​

Not available

Endpoints for modifying existing User resources are not available yet. Create a community feature request if those are important for your integrations.

Resend pending invitations​

POSThttps://api.tapeapp.com/v1/org/invitation/resend-pending

Resend all pending invitation emails for an organization. Needs the active user's organization role to be owner or admin.

➡️    Request
curl -X POST https://api.tapeapp.com/v1/org/invitation/resend-pending \
  -u user_key_replace_with_your_api_key:
⬅️    Response
{
