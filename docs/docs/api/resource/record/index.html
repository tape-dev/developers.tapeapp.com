Record

Use these endpoints to create, read, update, delete and restore the records of a database app.

To find records by text across all apps, use the Search resource.

In the Podio API, a record is an item: record_id replaces item_id, and app_record_id replaces app_item_id.

Which capability do I need?

Endpoints that read records need records:read. Endpoints that change records need records:edit. See Capabilities.

Authors​

created_by and last_modified_by hold one of three kinds of author. Check type to know which one you have.

typePropertiesDescription
"user"id, user_id, org_id, mail, email, name, and phone if setA user. user_id is the same as id.
"workflow"id, automation_id, workflow_id, mail, nameAn automation. automation_id is the same as id. workflow_id is deprecated.
"share_session"share_session_id, mail, nameA visitor who changed the record through a share link. Only in last_modified_by. share_session_id is a UUID string, mail is empty, and name is a generated label that isn't unique.

Create a record​

Use this endpoint to create a record in a database app.

POSThttps://api.tapeapp.com/v1/record/app/{app_id}

Before you start

  1. Open the database app in Tape, select ••• (Follow, export and more…) at the top, then select Developer. The window shows the App ID and, for every field, its Field ID and External ID (the field's slug). See Find the app ID and field IDs.
  2. Use a token with the capabilities Read records and Edit records (records:read, records:edit). The token from the Quickstart only reads records. Capabilities can't be added to a token later, so create a new token with every capability you need, for example Edit comments to comment on records.

Prefer the API? Retrieve all available apps returns every app_id. Retrieve a single app returns every field with its field_id and slug. Both need apps:read.

Don't see Developer?

You need Full access to the app.

Send the field values in the fields object, one key per field. Use the field ID or the field's slug (returned as external_id in records) as the key.

  • cURL
  • JSON
Request
curl -X POST https://api.tapeapp.com/v1/record/app/1 \
  -H "Authorization: Bearer $TAPE_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "fields": {
      "full_name": "Clara Weber"
    }
  }'
Request
{
  "fields": {
    "full_name": "Clara Weber"
  }
}
Response
{
  "record_id": 1,
  "app_id": 1,
  "title": "Clara Weber",
  "created_on": "2022-03-01 12:00:00",
  "fields": [
    {
      "field_id": 1,
      "external_id": "full_name",
      "label": "Full Name",
      "type": "text",
      "field_type": "single_text",
      "values": [
        {
          "value": "Clara Weber"
        }
      ]
    }
  ]
}

The response has status 201. The example sets one single_text field. For every other field type, see Field values.

To set a text field, send a string. To set a category field, send the label or the ID of the option:

Request
{
  "fields": {
    "full_name": "Clara Weber",
    "pipeline_stage": "Contacted"
  }
}

See Text field value and Category field value for every format.

Requirements: records:edit. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Errors

A request without a value for a required field returns 400 with validation, also for checklist, email, link and phone fields. An empty value, such as [] or null, counts as missing.

Query parameters

ParameterTypeDescription
silentbooleanDon't send notifications for this change (default: false).
hookbooleanRun webhooks for this change (default: true).
workflowbooleanTrigger automations for this change (default: true).
reject_unreferencable_relation_targetsbooleanReject the request with 400 if a relation value points to a record that can't be referenced. Otherwise, that reference is dropped (default: false).
reject_unresolvable_option_valuesbooleanReject the request with 400 if a category or status value matches no option. Otherwise, a category value is skipped. A status value without a match returns 400 in any case, because a status field can't be empty (default: false).
apply_user_timezone_on_date_inputsbooleanRead date values without a UTC offset in your timezone instead of UTC (default: false).

Retrieve a record​

Use this endpoint to read one record with all its field values.

GEThttps://api.tapeapp.com/v1/record/{record_id}
Request
curl https://api.tapeapp.com/v1/record/1 \
  -H "Authorization: Bearer $TAPE_TOKEN"
Response
{
  "record_id": 1,
  "app_id": 1,
  "title": "Clara Weber",
  "created_on": "2022-03-01 12:00:00",
  "fields": [
    {
      "field_id": 1,
      "external_id": "full_name",
      "label": "Full Name",
      "type": "text",
      "field_type": "single_text",
      "values": [
        {
          "value": "Clara Weber"
        }
      ]
    }
  ]
}

The response is shortened and shows one single_text field. A record also returns app_record_id (its number in the app), record_url, created_by and its revisions. See The record object.

A field without a value isn't in fields. A calculation whose result became empty is the exception: it stays with an empty values array.

Don't know a record ID?

Open the record in Tape, select ••• (Follow, export and more…), then select Developer. The window shows the Record ID. Or list the records of a database app with Retrieve records for an app.

Requirements: records:read. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Errors

A deleted record returns 400 with record_deleted:

{
  "status_code": 400,
  "endpoint": "/v1/record/17",
  "error_code": "record_deleted",
  "error_message": "[RecordDeletedException] Record with ID 17 is deleted!"
}

Query parameters

ParameterTypeDescription
include_deletedbooleanInclude records that are deleted but still in a trash you can access (default: false).

Update a record​

Use this endpoint to change the field values of a record.

PUThttps://api.tapeapp.com/v1/record/{record_id}

Send only the fields you want to change in the fields object. The response contains the updated record.

  • cURL
  • JSON
Request
curl -X PUT https://api.tapeapp.com/v1/record/1 \
  -H "Authorization: Bearer $TAPE_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{
    "fields": {
      "full_name": "Andrea Lim"
    }
  }'
Request
{
  "fields": {
    "full_name": "Andrea Lim"
  }
}
Response
{
  "record_id": 1,
  "title": "Andrea Lim",
  "created_on": "2022-03-01 12:00:00",
  "fields": [
    {
      "field_id": 1,
      "external_id": "full_name",
      "label": "Full Name",
      "type": "text",
      "field_type": "single_text",
      "values": [
        {
          "value": "Andrea Lim"
        }
      ]
    }
  ]
}

The example changes one single_text field. For every other field type, see Field values.

Requirements: records:edit. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Delete a record​

Use this endpoint to move a record to the trash.

DELETEhttps://api.tapeapp.com/v1/record/{record_id}
Request
curl -X DELETE https://api.tapeapp.com/v1/record/1 \
  -H "Authorization: Bearer $TAPE_TOKEN"
Response
{
  "record_id": 1,
  "title": "Clara Weber",
  "created_on": "2022-03-01 12:00:00",
  "deleted_on": "2022-03-01 13:00:00",
  "fields": [
    {
      "field_id": 1,
      "external_id": "full_name",
      "label": "Full Name",
      "type": "text",
      "field_type": "single_text",
      "values": [
        {
          "value": "Clara Weber"
        }
      ]
    }
  ]
}

To delete the record permanently, set skip_trash to true.

Requirements: records:edit. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Errors

A record that is already deleted returns 400 with record_deleted:

{
  "status_code": 400,
  "endpoint": "/v1/record/1",
  "error_code": "record_deleted",
  "error_message": "[RecordDeletedException] Record with ID 1 is deleted!"
}

Query parameters

ParameterTypeDescription
silentbooleanDon't send notifications for this change (default: false).
hookbooleanRun webhooks for this change (default: true).
workflowbooleanTrigger automations for this change (default: true).
skip_trashbooleanDelete the record permanently instead of moving it to a trash (default: false).

Restore a record​

Use this endpoint to bring a deleted record back from the trash.

POSThttps://api.tapeapp.com/v1/record/{record_id}/restore

The record must be in a trash you can access.

Request
curl -X POST https://api.tapeapp.com/v1/record/1/restore \
  -H "Authorization: Bearer $TAPE_TOKEN"
Response
{
  "record_id": 1,
  "title": "Clara Weber",
  "created_on": "2022-03-01 12:00:00",
  "fields": [
    {
      "field_id": 1,
      "external_id": "full_name",
      "label": "Full Name",
      "type": "text",
      "field_type": "single_text",
      "values": [
        {
          "value": "Clara Weber"
        }
      ]
    }
  ]
}

Requirements: records:edit. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Query parameters

ParameterTypeDescription

hookbooleanRun webhooks for this change (default: true).

      "created_on": "2026-08-03 09:14:22",
      "created_on_utc": "2026-08-03 07:14:22",
      "created_by": {
        "type": "user",
        "id": 5501,
        "user_id": 5501,
        "org_id": 77,
        "mail": ["juliet@acme.com"],
        "email": "juliet@acme.com",
        "name": "Juliet Adams"
      },
      "current_revision": null,
      "initial_revision": null
    }
  ],
  "cursor": null
}

The response is shortened. app also holds a config copy of its properties, and current_revision and initial_revision hold the record's latest and first revision. Each record is a preview with the same properties as a record result of the search.

General behavior

  • The list holds records shared with you through the record itself, in database apps you can't open otherwise. A shared record in a database you can open isn't listed. Read it with Retrieve records for an app.
  • Records come back as previews without field values. Read one in full with Retrieve a record.
  • To get the next page, send the returned cursor. Repeat until cursor is null. A full page doesn't mean that more pages exist.
  • The response has no total.
  • A personal access token with limited content access returns only the records in the databases its content access includes.

Requirements: records:read. Works with a personal access token, an OAuth access token or a user API key.

Errors

An automation API key returns 400 with validation, because it acts for no user.

Retrieve statistics of related records​

Use this endpoint to count or sum up a field over all records related to one record.

GEThttps://api.tapeapp.com/v1/record/{record_id}/reference/{field_id}/stats

The example sums up the number field 12 over all records related to record 1.

Request
curl "https://api.tapeapp.com/v1/record/1/reference/12/stats?aggregation_type=SUM" \
  -H "Authorization: Bearer $TAPE_TOKEN"
Response
{
  "result": 3,
  "source_record_id": 1,
  "target_field_id": 12
}

General behavior

  • The endpoint looks at every record of the field's app that is related to record_id, through incoming or outgoing relations.
  • It aggregates the field field_id over these records.

Requirements: records:read, and view access to the record and to the field's app. Works with a personal access token, an OAuth access token, a user API key or an automation API key.

Query parameters

ParameterTypeDescription
aggregation_typestringOne of COUNT (default), COUNT_NOT_EMPTY, COUNT_EMPTY, PERCENT_EMPTY, PERCENT_NOT_EMPTY, SUM, AVG, MEDIAN, MIN or MAX.

SUM, AVG, MEDIAN, MIN and MAX work only on number fields and on calculation fields that return a number.

Request

{

        "workspace_id": 1

The endpoint returns at most 10 records. It has no pagination and accepts no cursor or limit.

Requirements: records:read. Works with a personal access token, an OAuth access token or a user API key.
