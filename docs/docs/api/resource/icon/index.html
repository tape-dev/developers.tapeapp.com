Icon

Use an icon object to set the icon of an app or a workspace.

Icons represent records, apps and workspaces in the Tape web and mobile apps. Set them when you create or update an app or create or update a workspace.

Tape has three types of icons:

  • graphic icons
  • emoji icons
  • custom icons

The API supports graphic icons and emoji icons. Set custom icons in the Tape web app. An app or workspace with a custom icon returns no icon in the API.

Graphic icons​

A graphic icon is an icon provided by Tape. Its id identifies it.

Tape supports most icons of Google's Material Design icon library. To find the ID of an icon there, select the icon, select Android and copy the ID from the text field.

For example, hourglass_empty is the icon of an hourglass. An id Tape doesn't support returns 400 with validation.

Send this object to set a graphic icon:

Icon
{
  "id": "hourglass_empty",
  "type": "graphic"
}
PropertyTypeDescriptionExample value
typestring"graphic" for a graphic icon."graphic"
idstringID of the icon in the Material Design icon library."hourglass_empty"

Emoji icons​

An emoji icon is a Unicode emoji. Its emoji property identifies it.

Send this object to set an emoji icon, here the telephone receiver emoji (U+1F4DE). The example writes it as a JSON escape. You can also send the emoji character itself.

Icon
{
  "emoji": "\ud83d\udcde",
  "type": "emoji"
}
PropertyTypeDescriptionExample value
typestring"emoji" for an emoji icon."emoji"
emojistringThe emoji, as a JSON escape or as the character itself."\ud83d\udcde"
Can I send a string instead of an object?

Yes. Tape reads an emoji as an emoji icon and any other text as the id of a graphic icon.
