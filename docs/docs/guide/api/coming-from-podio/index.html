Tape API

Coming from the Podio API

Move an integration from the Podio API to the Tape API with the same concepts and familiar endpoints.

Tape and Podio share their building blocks: organizations, workspaces, apps, fields, views, and webhooks. Most scripts need new names, a new base URL, and a new token.

Before you begin​

You need a Tape organization with your apps in it. Moving a whole Podio organization? Use the free Zooli Migration Tool first, as described in Migrate to Tape, then point your code at Tape.

The migration gives your apps, fields, and records new IDs. Replace the old IDs and external_id values in your scripts. The Developer view of each app lists the new IDs and slugs.

Tape builds each field slug from the field name, with underscores instead of hyphens. A Podio external_id like due-date usually becomes due_date.

Send every request to https://api.tapeapp.com. The API sends and receives JSON.

Switch authentication​

Replace the Podio header Authorization: OAuth2 <token> with a bearer token:

curl https://api.tapeapp.com/v1/user \
  -H "Authorization: Bearer $TAPE_TOKEN"

Choose the credential that matches your Podio flow:

Podio flowUse in Tape
Server-side flow, for your own scriptsPersonal access token. It can also act on a user's behalf when that user creates it
Server-side flow, for a product other Tape users connectOAuth with PKCE and a client registered by Tape
Client-side flowOAuth with PKCE and a public client registered by Tape, no client secret needed
Username and password flowPersonal access token
App authenticationPersonal access token with its content access limited to that app and only the capabilities your script needs. Tape has no token per app. Records, comments and revisions show the token's user as the author, so create the token from a dedicated user for the integration. See Attribution

Move your webhooks​

Webhooks verify the same way. Tape sends type hook.verify with a code, and your endpoint calls Validate hook verification.

What changes:

  • Tape sends hook.verify right after you create a webhook. Call Request hook verification only if your endpoint missed it.
  • Tape sends a JSON body, not form parameters.
  • Events start with record. instead of item., for example record.create. Tape adds record.restore.
  • The payload carries record_id and revision_id instead of item_id and item_revision_id.
  • Webhooks apply to a whole app. To react to one field, use an automation with a filter.

A minimal handler in Node.js:

app.post('/tape-webhook', async (req, res) => {
  const { type, hook_id, code, record_id } = req.body;
  res.sendStatus(200);
  if (type === 'hook.verify') {
    await fetch(`https://api.tapeapp.com/v1/hook/${hook_id}/verify/validate`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${process.env.TAPE_TOKEN}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ code }),
    });
  }
  if (type === 'record.create') {
    // For example, create a follow-up task for a new lead.
  }
});
How do you avoid endless loops?

Update a record from a webhook with hook=false, as in the Podio API, plus workflow=false, because hook=false doesn't stop automations. Add silent=true to skip notifications. See Avoid endless loops.

Move your flows​

A Podio flow or a Globiflow flow becomes an automation in one app. Field references use the field_id, not the external_id. Find the action for each flow step in Coming from Podio.

Plan for request limits​

Tape counts credits per minute instead of calls per hour. All credentials of a user share one budget, so more tokens don't add throughput.

Each response carries rate limit headers. After a 429, wait the seconds in Retry-After before you retry. See Request limits.

Good to know​

  • Tape has no client libraries for PHP or Ruby. Call the API over HTTPS from any language.
  • Tasks, status updates, and the activity stream have no Tape endpoints. Use a checklist field and record revisions instead.
  • Tape adds endpoints the Podio API doesn't have: batch create and update, restore a record, the Automation API, and the Tape MCP server.
