Scripting

Available libraries (automations)

Use these Node.js libraries in the code of your automations without importing them.

They work in script filters, Perform a calculation and Execute a script. Call each library by its alias. Example: format a date with date-fns.

date_fns.format(new Date(current_datetime_local), 'yyyy-MM-dd')
LibraryAliasesVersionDescription
Lodashlodash, _4.17.21Utility functions for arrays, objects and strings.
Moment.jsmoment2.30.1Parse, validate, change and format dates and times.
date-fnsdate_fns2.30.0Date utility functions.
date-fns-tzdate_fns_tz2.0.1Timezone support for date-fns, based on the Intl API.
uuiduuid8.3.2Create RFC4122 UUIDs.
cheeriocheerio1.0.0-rc.10Parse and read HTML on the server, with a jQuery-like API.
striptagsstriptags3.2.0Remove HTML tags from a string, like PHP's strip_tags.
minimatchminimatch9.0.5Match strings against glob patterns.
jsonatajsonata1.8.6Query and transform JSON, see the JSONata documentation.
