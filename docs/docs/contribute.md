# Contribute

> Help improve these docs by proposing a change on GitHub.

Help improve these docs by proposing a change on GitHub.

## Propose a change

1.  Open the page you want to improve.
2.  Select **Edit this page** at the bottom of the page.
3.  Make your change on GitHub and open a pull request.

A team member reviews your pull request. Once it's approved and merged, your change goes live with the next publish of the docs.
